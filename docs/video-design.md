# Video design gate

Use Anthropic’s project-local `frontend-design` skill for art direction and `remotion-best-practices` for implementation. Translate the web guide to a fixed video frame: the hero is the opening shot, responsive checks become checks at each requested aspect ratio and at typical playback size, and motion follows the scene's beat rather than browser events.

1. **Plan before JSX/CSS.** Name the audience, one visual reference from the subject's world, the focal element of the opening shot, and the palette, type and layout that make sense for that subject. Give each major motion cue a purpose: reveal, explain or direct attention. If the same treatment would fit an unrelated brief unchanged, revise it before handing it to the builder.
2. **Build from the plan.** Use the requested look when specified. Otherwise make hierarchy with composition and typography before adding ornament. Keep gradients, badges, floating cards, decorative labels and repeated fade-up entrances only when they serve this brief. Don't reuse `Demo` as a style template. Use frame-driven animation and locally available assets and fonts.
3. **Review frames before final export.** Scrub one Studio session to the opening, the busiest scene or caption frame, and the closing (or representative equivalents for a short overlay). Render stills only when Studio inspection is unavailable or a still is needed for review. At delivery aspect and typical viewing size, check focal point, text contrast and size, safe margins, and whether the imagery, typography and motion feel specific to the subject. Fix and recheck failures. If frames can't be inspected under the media privacy rules, give the user local preview paths and say that visual review is pending; a successful render isn't a visual pass.
